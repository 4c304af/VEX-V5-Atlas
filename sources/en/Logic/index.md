# Logic

The Logic pages collect the core C++ language features and helper classes used to control program flow, store data, organize reusable code, and handle timing, events, or utilities that are not tied to a specific device.

- **[Control](Control.md)** - Manages project flow using conditionals and loops.
- **[Math](Math.md)** - Provides mathematical operations and built-in calculation functions.
- **[Random](Random.md)** - Generates random numbers and selects random values.
- **[Operators](Operators.md)** - Compares values, combines expressions, and performs logical tests.
- **[Comments](Comments.md)** - Write notes inside of the code without affecting project execution.
- **[Events](Events.md)** - Lets you define and trigger event-driven behavior using broadcast functions.
- **[Variables](Variables.md)** - Stores and manages data used throughout your program.
- **[Functions](Functions.md)** - Groups reusable blocks of code into callable units.
- **[Threads](Threads.md)** - Allows multiple parts of a program to run concurrently.
- **[Custom Timer](Custom_timer.md)** - Measures time intervals and triggers actions after a set duration.
- **[Custom Colors](Custom_color.md)** - Defines custom colors using RGB or hexadecimal values.
- **[String Formatting](Custom_formatting.md)** - Formats text and numerical output for display.

Together, these features provide the foundational tools for building structured, responsive, and maintainable C++ projects.
