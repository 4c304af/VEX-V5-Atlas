# CTE Workcell

The VEX CTE Workcell includes specialized devices used to simulate automated material handling and industrial control systems. These devices provide precise motion control and sensing within the VEX CTE Workcell environment.

Below is a list of available CTE Workcell devices:

- [**Arm**](Arm.md) - A 6-Axis robotic arm that provides precise positioning and movement control for pick-and-place operations and complex manipulations.
- [**Object Sensor**](ObjectDetector.md) - Detects the presence and properties of objects within the workcell environment for automated sorting and handling.
- [**Pneumatics**](Pneumatics.md) - Controls pneumatic solenoids for air-powered actuators and mechanisms in the workcell.
- [**Signal Tower**](SignalTower.md) - A visual indicator system with multiple colored LEDs and button input for status monitoring and user interaction.
