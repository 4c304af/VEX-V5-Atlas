# Motor Controller 55

```{contents}
:local: true
```

## Introduction

The <code>motor55</code> class is used to control a VEX Motor Controller 55 connected to the V5 Brain. The Motor Controller 55 is a legacy motor controller designed to operate 2-wire DC motors.

![The VEX Motor Controller 55.](/_static/img/motion/mc-55.png)

## Class Constructors

> **__1__ —** Creates a <code>motor55</code> object on the specified Smart Port.
> ```cpp
> motor55(
>   int32_t index );
> ```

> **__2__ —** Creates a <code>motor55</code> object on the specified Smart Port and changes the positive turning direction.
> ```cpp
> motor55(
>   int32_t index,
>   bool    reverse );
> ```

> **__3__ —** Creates a <code>motor55</code> object on the specified Smart Port, sets the maximum drive voltage, and changes the positive turning direction.
> ```cpp
> motor55(
>   int32_t index,
>   double  maxv,
>   bool    reverse );
> ```

## Class Destructor

Destroys the <code>motor55</code> object and releases associated resources.

```cpp
~motor55();
```

## Parameters

| Parameter | Type | Description |
|:--:|:--:|--|
| <code>index</code> | <code>int32_t</code> | The Smart Port that the Motor Controller 55 is connected to, written as <code>PORTx</code>, where <code>x</code> is the port number (for example, <code>PORT1</code>). |
| <code>reverse</code> | <code>bool</code> | Determines whether the motor's direction is reversed:<ul><li><code>true</code> — The motor's positive direction is reversed.</li><li><code>false</code> — The motor's positive direction remains normal.</li></ul> |
| <code>maxv</code> | <code>double</code> | The maximum voltage that the Motor Controller 55 can apply to the motor. |

## Example

```cpp
// Create the motor55 instance in Smart Port 1
motor55 Motor1 = motor55(PORT1);
```

### spin

```{vexcode}
id: v5_motion_mc55_spin
```

```{vexcode}
id: v5_motion_mc55_spin_at_voltage
```

Spins the motor in the specified direction indefinitely.

<span style="font-size: 1.5rem;"> Available Functions </span>

> **__1__ —** Spins using the [currently configured velocity](#setvelocity).
> ```cpp
> void spin(
>   directionType dir );
> ```

> **__2__ —** Spins at the specified voltage.
> ```cpp
> void spin(
>   directionType dir,
>   double        voltage,
>   voltageUnits  units );
> ```

<span style="font-size: 1.5rem;"> Parameters </span>

|       Parameter      |            Type            | Description                                                                                                         |
| :------------------: | :------------------------: | ------------------------------------------------------------------------------------------------------------------- |
|   <code>dir</code>   | <code>directionType</code> | The direction in which the motor spins: <code>forward</code> or <code>reverse</code>. |
| <code>voltage</code> |     <code>double</code>    | The voltage value applied to the motor. A negative value spins opposite the given <code>dir</code>. |
|  <code>units</code>  |  <code>voltageUnits</code> | The unit used to represent voltage:<ul><li><code>volt</code> — volts</li><li><code>voltageUnits::mV</code> — millivolts</li></ul> |

<span style="font-size: 1.5rem;"> Return Values </span>

This function does not return a value.

<span style="font-size: 1.5rem;"> Notes </span>

- This function is non-waiting and the program continues immediately after the call.
- The motor will continue spinning until [<code>stop</code>](#stop) is called or another <code>spin</code> is used.

### setVelocity

```{vexcode}
id: v5_motion_mc55_set_velocity
```

Tells a DC motor how fast to spin. A higher percentage makes the DC motor spin faster and a lower percentage makes the DC motor spin slower.

Every project begins with each connected DC motor spinning at 50% velocity by default.

<span style="font-size: 1.5rem;"> Available Functions </span>

```cpp
void setVelocity(
    double       velocity,
    percentUnits units = percent );
```

<span style="font-size: 1.5rem;"> Parameters </span>

|       Parameter       |            Type           | Description                                                                                                               |
| :-------------------: | :-----------------------: | ------------------------------------------------------------------------------------------------------------------------- |
| <code>velocity</code> |    <code>double</code>    | The velocity to spin with from 0% to 100% when using <code>percent</code>.                                                                                 |
|   <code>units</code>  | <code>percentUnits</code> | The velocity unit:<ul><li><code>percent</code> / <code>pct</code> (default) — percent</li></ul> |

<span style="font-size: 1.5rem;"> Return Values </span>

This function does not return a value.

<span style="font-size: 1.5rem;"> Notes </span>

- Any subsequent call to [<code>spin</code>](#spin) without a specified voltage will use this value.

### current

<code>current</code> returns how much electrical current the DC motor is using. Current is the amount of electricity flowing through the DC motor. When returned in amps, current is reported from 0.0 to 1.2 A.

A higher current value means the DC motor is using more electrical current. This can happen when the DC motor is lifting something heavy, pushing against an object, or trying to move when it is stuck.

This can be used to check if the DC motor is struggling during a movement. If current stays high, the motor may get warmer or use power less efficiently.

<span style="font-size: 1.5rem;">
  Available Functions
</span>

> **__1__ —** Returns the DC motor’s electrical current in amps.
> ```cpp
> double current(
>   currentUnits units = amp );
> ```

> **__2__ —** Returns the DC motor’s electrical current as a percentage of maximum rated current.
> ```cpp
> double current(
>   percentUnits units );
> ```


<span style="font-size: 1.5rem; ">
  Parameters
</span>

| Parameter | Type | Description |
|:--:|:--:|--|
| <code>units</code> | <code>currentUnits</code> | The unit used to represent current:<code>amp</code> (default) — amperes |
| <code>units</code> | <code>percentUnits</code> | Represents current as a percentage of the motor's maximum rated current:<code>percent</code> / <code>pct</code> — percent |


<span style="font-size: 1.5rem; ">
  Return Values
</span>

Returns a <code>double</code> representing how much electrical current the DC motor is using in the specified units.

### temperature

<code>temperature</code> returns the temperature of the DC motor.

Motor temperature shows how warm the DC motor is. A higher temperature means the DC motor is getting warmer while it works. The motor should stay below 55°C to keep working at full performance.

If the DC motor gets too hot, it will lower its maximum current to protect itself. At 70°C, the motor will stop running until it cools down.

This can be used to check if the DC motor is getting too hot during repeated movements, long runs, or when it is pushing against an object.

<span style="font-size: 1.5rem;">
  Available Functions
</span>

> **__1__ —** Returns DC motor temperature as a percentage of maximum operating temperature.
> ```cpp
> double temperature(
>   percentUnits units = percent );
> ```

> **__2__ —** Returns DC motor temperature in physical temperature units.
> ```cpp
> double temperature(
>   temperatureUnits units );
> ```

<span style="font-size: 1.5rem;"> Parameters </span>

| Parameter | Type | Description |
|:---------:|:----:|:------------|
| <code>units</code> | <code>percentUnits</code> | The unit used to represent DC motor temperature as a percentage:<ul><li><code>percent</code> / <code>pct</code> (default) — percent</li></ul> |
| <code>units</code> | <code>temperatureUnits</code> | The unit used to represent DC motor temperature in degrees:<ul><li><code>celsius</code> — degrees Celsius</li><li><code>fahrenheit</code> — degrees Fahrenheit</li></ul> |

<span style="font-size: 1.5rem;"> Return Values </span>

Returns a <code>double</code> representing the DC motor's temperature in the specified units.

<span style="font-size: 1.5rem;"> Notes </span>

- The operating temperature range for the motor is approximately <code>20°C</code> (<code>68°F</code>) to <code>70°C</code> (<code>158°F</code>).
