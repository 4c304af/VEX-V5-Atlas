V5 Atlas 1.2.0 · VEX V5 C++ 双语离线参考

关闭旧版，将 V5-Atlas-1.2.0-Windows-x64.exe 放到原来的可写入文件夹中双击运行。
请保留程序旁的 .v5-atlas 文件夹，其中保存收藏、偏好和文档更新。

Ctrl+K：本地全文搜索。
顶部“中 / EN / 对照”：切换中文、英文和中英对照。
阅读页右上角：收藏、打开官方来源。

默认在启动时及每 6 小时检查双语文档包与程序版本。
在左侧“文档更新”中，可分别关闭自动更新，也可点击“立即同步并检查新版”。
文档包整体验证通过后，新增页面自动加入文档库和全文搜索，无需重装。
GitHub 工作流每小时检查官方英文内容，完成翻译和校验后发布双语包；调度和网络可能延迟。
新内容采用机器辅助翻译、术语保护和现有语义校订规则，可随时与英文对照。

新版程序下载好后，更新页会出现“重启并更新”。点击后替换程序并重启，保留 .previous 旧版备份。
旧版 1.0.2 及以前没有自更新能力，需要先手动升级到本版。
更新失败或取消时保留已有离线文档；收藏、阅读历史和偏好独立保存。

“立即检查”仍可逐页对比 VEX 官方英文文档，查看新增、修改与移除；支持取消与离线查看上次结果。
自动同步从本项目 GitHub 发布页获取数据，不会在应用内发送文档进行翻译。
无网络时，文档查阅、搜索、复制代码和配图正常可用。

运行平台：Windows 10/11 x64，系统需有 Microsoft Edge WebView2 Runtime。
启动错误详情保存在程序旁的 V5Atlas-startup.log。
项目：https://github.com/4c304af/offline-vexv5cpp-api

赛事规则：左侧新增“赛事规则”，按 12 个分区浏览 Override v2.1，支持编号和中英文搜索、收藏、中英对照及原页配图。中文为 Codex 撰写的条款要点译解，非逐句全文翻译；细则及处罚须核对英文、官方原页和官方 Q&A。
